# Accountify API

Accountify is a comprehensive RESTful API built with Java and Spring Boot. It provides endpoints for managing accounting entities such as ledgers, bills, and journal entries. The API is secured using Firebase Authentication (JWT) and utilizes MySQL for robust data storage.

## Features

- **Ledger Management**: Create, update, and manage financial ledgers.
- **Bill Entry Module**: Full lifecycle management of bills including tax types and rates.
- **Journal Entries**: Facilitate complex accounting operations.
- **Secure Authentication**: Built-in OAuth2 Resource Server protecting endpoints via Firebase JWTs.
- **API Documentation**: Interactive Swagger UI generated by Springdoc.

## Tech Stack

- **Language**: Java
- **Framework**: Spring Boot 3.x
- **Database**: MySQL, managed via Flyway migrations
- **Security**: Spring Security (OAuth2 JWT) & Firebase Auth (Google)
- **Documentation**: Springdoc OpenAPI / Swagger UI

## Prerequisites

Before running this project, ensure you have the following installed:

- **Java 17** (or compatible newer version)
- **Maven** (optional, you can use the included `mvnw` wrapper)
- **MySQL** instance running locally or remotely
- A **Firebase Project** for JWT validation (or mock tokens for testing)

## Local Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/MohanJPOfficial/Accountify.git
   cd Accountify
   ```

2. **Configure Environment Variables**
   The application uses environment variables for database credentials and Firebase configuration.
   Copy the provided `.env.example` file to create a `.env` file:
   ```bash
   cp .env.example .env
   ```
   Open the `.env` file and replace the placeholder values with your actual database and Firebase credentials:
   ```properties
   DB_URL=jdbc:mysql://localhost:3306/accountify?createDatabaseIfNotExist=true
   DB_USERNAME=root
   DB_PASSWORD=your_secure_password
   FIREBASE_PROJECT_ID=your_firebase_project_id
   ```

3. **Database Migration**
   The project uses Flyway. The application will automatically run migration scripts (`src/main/resources/db/migration/`) upon startup to configure the schema.

4. **Run the Application**
   You can start the application using the Maven wrapper:
   ```bash
   ./mvnw spring-boot:run
   ```
   Or, if you have Maven installed globally:
   ```bash
   mvn spring-boot:run
   ```

## Exploring the API

Once the application is running (by default on port `8080`), you can interact with the API through the Swagger UI:

- **Swagger UI**: [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)
- **OpenAPI JSON**: [http://localhost:8080/v3/api-docs](http://localhost:8080/v3/api-docs)

### Authentication

To test secured endpoints in Swagger or Postman:
1. Obtain relatively freshly minted ID tokens from your Firebase application.
2. Provide the token via the `Authorization` header as a Bearer token:
   `Authorization: Bearer <your-firebase-jwt>`
